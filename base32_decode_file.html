What is Base32 encoding?

Base32 is a binary-to-text encoding defined by RFC 4648. It represents bytes using the 32 characters A-Z and 2-7, with = padding. Encoded data is about 60% larger than the original.

Common uses: TOTP/2FA secret keys, onion addresses and case-insensitive identifiers.

How to decode Base32 online

  1. Paste the Base32 string into the Input area.
  2. Adjust the character encoding or options in Settings if needed.
  3. Download the decoded file.

Conversion runs locally in your browser. Your data is never uploaded.

Frequently asked questions

Is Base32 encryption?

No. Base32 is an encoding, not encryption. Anyone can decode it, so never use it to hide secrets.

Is this Base32 decoder free and private?

Yes. It is free, needs no account, and runs entirely in your browser.

Why is my Base32 output larger than the input?

Base32 uses fewer bits per character than raw bytes, so output grows by about 60%.
