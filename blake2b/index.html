What is BLAKE2b?

BLAKE2b is a hash function from the BLAKE2 family, introduced in 2012 by Aumasson, Neves, Wilcox-O'Hearn and Winnerlein (RFC 7693). It turns input of any size into a fixed 512-bit (128 hex character) digest. The same input always gives the same output, and a one-bit change in the input gives a completely different result.

Security status: BLAKE2b is secure and faster than MD5 on 64-bit CPUs.

Common uses: Argon2 password hashing, WireGuard, libsodium generichash and file deduplication.

How to calculate BLAKE2b online

  1. Type or paste your text into the Input box.
  2. Choose the input encoding (UTF-8, UTF-16, Hex or Base64) if needed.
  3. The BLAKE2b hash appears instantly in the Output box while Auto Update is on.
  4. Click the copy icon, or use Share Link to send the exact input and settings.

Everything runs in your browser with JavaScript. Your text is never uploaded to a server.

Frequently asked questions

Is this BLAKE2b tool free and private?

Yes. It is free with no sign-up, and the BLAKE2b calculation runs entirely in your browser. Nothing you enter is sent to our servers.

Can I reverse or decrypt a BLAKE2b hash?

No. BLAKE2b is a one-way function, so the original input cannot be recovered from the output. Sites that "decrypt" hashes only look them up in tables of precomputed common inputs.

How long is a BLAKE2b hash?

A BLAKE2b digest is 512 bits, which is 64 bytes or 128 hexadecimal characters.

Should I use BLAKE2b to store passwords?

No fast hash should store passwords on its own. Use Argon2id, bcrypt or scrypt, which are slow and salted by design.

Why does my hash differ from another tool?

Check the input encoding and trailing newlines. "abc" and "abc\n" hash differently, and UTF-8 and UTF-16 produce different bytes for the same text.
