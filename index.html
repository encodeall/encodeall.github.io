Why use EncodeAll?

EncodeAll is a free collection of more than 110 developer tools for hashing, encoding, decoding, formatting and generating data. Every tool runs entirely in your browser with JavaScript or WebAssembly, so the text and files you enter never leave your device.

  • Hash generators: MD5, SHA-1, SHA-256, SHA-512, SHA-3, Keccak-256, BLAKE2, BLAKE3, RIPEMD-160, CRC32 and more, for both text and files, with HMAC support.
  • Encoders and decoders: Base64, Base32, Base58, Hex, URL and HTML, including file conversion.
  • Formatters: JSON formatter, minifier and tree viewer, plus XML formatter and minifier.
  • Developer utilities: UUID v4/v7 generator, secure password generator, JWT decoder, Unix timestamp converter, word counter and Lorem Ipsum generator.

Frequently asked questions

Are these tools free?

Yes. Every tool is free to use with no account and no usage limits. The site is supported by advertising.

Is my data uploaded?

No. Hashing, encoding and formatting run locally in your browser. You can even disconnect from the internet after the page loads.

Which hash should I use?

For general integrity checks use SHA-256 or BLAKE3. Avoid MD5 and SHA-1 for anything security-related. For passwords use a slow, salted hash such as Argon2id or bcrypt.
