Password Generator

Create strong, random passwords with custom length, symbols and numbers using cryptographically secure randomness. Nothing leaves your browser.

Passwords
Settings

How this password generator works

Passwords are built with your browser's cryptographically secure random number generator (crypto.getRandomValues()) using unbiased rejection sampling. Each password contains at least one character from every set you select. Nothing is stored or sent over the network.

How strong should a password be?

Strength is measured in bits of entropy: length × log2(alphabet size). Aim for at least 80 bits for important accounts. A 16-character password using upper case, lower case, digits and symbols gives about 100 bits. Length matters more than complexity, so use a password manager and make passwords long.

Frequently asked questions

Is it safe to generate passwords online?

This generator runs entirely in your browser and never transmits the result. You can load the page, go offline and it still works.

How long should my password be?

At least 12 characters for everyday accounts and 16 or more for email, banking and password-manager master passwords.

Should I reuse passwords?

No. Use a unique password for every site so one breach cannot unlock your other accounts.
